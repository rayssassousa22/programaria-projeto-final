# Dicionário de Mulheres Negras
# Descrição
O projeto "Dicionário de Mulheres Negras" é um site dedicado a listar e explorar as histórias de mulheres negras que tiveram e continuam a ter um impacto significativo na história do Brasil e do mundo. Este site oferece uma visão sobre as contribuições e legados dessas mulheres incríveis.

# Estrutura do Projeto
Arquivos
- index.html: O arquivo principal HTML que define a estrutura e o conteúdo do site.
- assets/css/stylesheet.css: Folha de estilo para a formatação do site.
- assets/js/main.js: Arquivo JavaScript para interatividade (não implementado no código fornecido).
Conteúdo do index.html
Cabeçalho (<header>)

Título principal: "Dicionário de Mulheres Negras"
Subtítulo: "Dicionário que lista todas as mulheres que fizeram e ainda fazem parte da história do Brasil e do mundo"
Corpo (<main>)

Seção principal com um subtítulo para explorar as histórias das mulheres.
Seção <section id="dicionario"> para exibição das informações sobre as mulheres (ainda não implementada).
Rodapé (<footer>)

Informações de autoria: "Made By Rayssa Sousa"
Links para GitHub e LinkedIn da autora.
Tecnologias Utilizadas

JavaScript (Arquivo main.js incluído, mas não implementado no código fornecido)
